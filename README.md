# Student Portal

A C++ based student portal developed as part of the SSD Git Lab activity.

The project demonstrates Git-based development using separate feature branches,
meaningful commits, merging, file operations, conflict resolution, stash,
reflog recovery, and release tagging.

The student portal centralizes academic information, personal details, and
account management in one application.

## Features

- User Login
- Student Profile
- Dashboard
- Settings
- Logout
